# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Instalación local

- Se instaló la plantilla oficial `LazyVim/starter` porque `~/.config/nvim` no existía.
- Se conservaron los datos previos de Neovim (plugins, estado y caché) en una copia fechada bajo `~/.local/share/nvim-backup-*`; no se mezclaron con esta instalación nueva.
- Se mantuvo la compatibilidad con el stack existente: Neovim `0.12.4` y Git ya estaban disponibles.
